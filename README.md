# Personal Finance Tracker — 2024

## Project Overview
An end-to-end data analysis project tracking personal 
income, expenses, savings and budget performance 
across 12 months of 2024.

## Tools Used
- SQL Server — Data storage and analytical queries
- Microsoft Excel — Data cleaning and variance analysis
- Microsoft Power BI — Interactive dashboard

## Database Schema
- categories
- monthly_budget
- transactions
- savings_goal

## Key Insights
- Total Annual Income: ₹5,85,000
- Total Annual Savings: ₹1,90,000
- Average Savings Rate: 32.31%
- Entertainment overspent 11 out of 12 months
- January had highest savings rate at 43.96%
- August had lowest savings rate at 21.49%

## SQL Queries
10 analytical queries covering:
1. Total Income vs Expenses per Month
2. Monthly Actual Savings
3. Top 3 Spending Categories
4. Budget vs Actual Spending
5. Savings Goal vs Actual
6. Months Where Expenses Exceeded Income
7. Category-wise Overspending Frequency
8. Savings Rate per Month
9. Running Total of Savings
10. Highest Single Transaction per Category
